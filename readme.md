# Workers
- d3erver: a "self-host" solution for Foundry modules
- Email: sends emails by URL invoke
- Images: hosts images with open cors used for stargazer

### 2026
- desire-selection: select TTRPG player character desires from Good Society RPG
- liminal-cockpit: tools for running Liminal Horror
- mosh-cockpit: a cockpit for running Mothership
- one-year-to-descend: cheatsheet site for the One Year to Descend Mothership module
- oubliette: a cockpit for running Oubliette
- oubliette-readable: readable Oubliette, with an iframe variant for vtt-oubliette
- reactive-discord-avatar-selector: reactive Discord avatar selector
